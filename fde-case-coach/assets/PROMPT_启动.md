# WS1 启动 Prompt（全场只需这一条）

## 使用方式（两步）

1. 把《SKILL_案例实战教练》**全文**粘贴给 WorkBuddy，附一句："请加载这个 Skill，严格遵守其中的流程与规则。"
2. 把下面整段（从"你是"到"开始。"）粘贴发送——对话即自动进入第 1 轮。

此后不需要任何其他 Prompt：访谈、PRD、原型三个阶段共约 20 轮对话，流程由 Skill 主导。

**前 5 轮是访谈：WorkBuddy 扮演恒润的人（小周 / 王工），你们来问。** 像真实客户一样，它不问不答——表层问题只能得到表层答案，挖多深全看你们怎么问。你们手里真正影响走向的动作有两个：**问好问题**，以及对 Skill 给出的每个【假设】明确说"认可"或"不认可"。

**兜底说明**：Skill 内置保底机制——即使全程只说"继续"，20 轮后也会得到一份结构完整、不违反红线的 PRD 和原型。但那样的产出里，每个决策都标着【教练补充·假设】，复盘时你们需要解释：为什么你们组的产出和隔壁"躺平组"长得一样。

## 启动 Prompt（整段复制）

```
客户背景资料如下：

【背景】
苏州恒润精工，约 300 人，做精密 CNC 零部件，客户是医疗设备与自动化设备厂商。销售 12 人，报价靠 3 位老工程师翻历史订单、凭经验定。老板的原话："给我们做一个 AI 报价助手。"

【已知事实】
1. 询盘每天 30–40 条，旺季 60+；六成是老客户重复询价
2. 报价平均耗时 2 天；客户往往等不到 1 天就去比价
3. 报价单散落在 3 位工程师的个人 Excel，格式各不相同
4. 历史订单在 ERP 里，但近两年的工艺变更没有录入
5. 材料价格每周波动，Excel 里的材料价半年未更新
6. 最年轻的报价工程师 38 岁，经验从未交接过
7. 老板之子今年入职分管数字化，是本项目发起人
8. 去年 40 万上的"智能排产"，用了三个月就搁置了

开始。
```

## 时间建议（30 分钟）

| 阶段 | 用时 | 提示 |
|---|---|---|
| 读题与分工 | 2′ | 建议 2 人轮流对话、1 人记录分歧点 |
| 对话实战 | 25′ | 卡壳超过 2 分钟就回复"按你的建议继续"，粗版优先 |
| 整理与提交 | 3′ | 群文件提交，命名"组号-恒润PRD" |
