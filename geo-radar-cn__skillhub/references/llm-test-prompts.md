# LLM 测试 Prompt 模板(v2.0 真实 GEO 跑批用)

v2.0 的核心是**直接问 LLM**,所以 prompt 设计要从"web_search 关键词"升级为"用户真实会问的问题"。

## 设计原则

1. **像真人一样问**:用完整问句,不用关键词堆砌
2. **4 类分布**:推荐型 / 对比型 / 痛点型 / 决策型 各 5-7 个
3. **场景化**:针对真实用户决策场景(找品牌 / 选哪个 / 怎么选 / 适合谁)
4. **不带品牌名**(品牌由 skill 注入)— 避免"蜜雪冰城怎么样"这种自问自答
5. **可执行**:用户拿这个 prompt 列表,自己也能在豆包/Kimi 问

## 8 行业 × 4 类型 Prompt 库

### 奶茶行业(蜜雪冰城 / 古茗 / 喜茶 / 茶百道)

**推荐型(找品牌):**
- "推荐 2025 最受欢迎的奶茶品牌"
- "高性价比奶茶排行,平价好喝的那种"
- "学生党喝什么奶茶,便宜又不踩雷"
- "下沉市场最火的奶茶品牌是哪些"
- "适合日常喝的奶茶品牌,不要太甜的"

**对比型(品牌 PK):**
- "蜜雪冰城 vs 古茗 哪个更适合投资"
- "喜茶和奈雪的茶有什么区别"
- "茶百道和古茗哪个更值得加盟"
- "平价奶茶里,蜜雪冰城和益禾堂哪个更好"
- "高端奶茶品牌对比,喜茶奈雪霸王茶姬"

**痛点型(找解决方案):**
- "想开奶茶店但不懂选址,怎么开始"
- "加盟奶茶店被骗了怎么办,如何避坑"
- "奶茶店生意不好,怎么提升销量"
- "开奶茶店需要哪些设备和原料"
- "奶茶店员工培训怎么做才有效"

**决策型(分场景):**
- "学生党预算 10 元,买哪款奶茶"
- "上班族下午茶推荐什么奶茶"
- "夏天适合喝什么奶茶,不甜腻"
- "冬天暖身奶茶推荐"
- "减肥期间能喝什么奶茶"

### SaaS 行业(Notion / Figma / Slack)

**推荐型:**
- "2025 最好用的团队协作工具推荐"
- "免费的项目管理工具,适合小团队"
- "AI 写作工具排行"

**对比型:**
- "Notion vs Obsidian 哪个适合做笔记"
- "Figma 和 Sketch 哪个更适合 UI 设计"

**痛点型:**
- "团队协作效率低,有什么工具能提升"
- "文档管理混乱,怎么解决"

**决策型:**
- "远程办公用什么协作软件"
- "学生用什么笔记软件好"

## 自定义 Prompt 库

用户也可以传自己的 prompts(JSON 数组):

```json
[
  "推荐 2025 中国最受欢迎 SaaS 工具",
  "Notion 适合中国市场吗",
  "Notion vs 飞书哪个更好用",
  "中小企业用什么 CRM 比较好",
  "远程团队用什么笔记软件"
]
```

## Prompt 质量自检

| 标准 | 必填 |
|---|---|
| 像真人问句(有"吗/呢/推荐/对比"等) | ✅ |
| 4 类齐全(推荐/对比/痛点/决策) | ✅ |
| 数量 ≥ 20(默认 20-30) | ✅ |
| 不带具体品牌名(品牌由 skill 注入) | ✅ |
| 中文表达自然流畅 | ✅ |
| 符合用户真实决策场景 | ✅ |

跑批前 skill 会在报告第 6 节"自动生成的 prompt 列表"里展示所有 prompt,用户可审。
