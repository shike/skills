# GEO 雷达 · Skill 商店展示卡

## 主标题

**GEO 雷达：基于公开数据的多 AI 引擎可见度诊断与优化指引**

## 一句话简介

输入品牌名,自动生成 20-30 个查询词,跑批 web_search 统计 AI 引用源,输出 8 节结构化报告,告诉你"AI 看不看你的品牌 + 怎么改进"。

## 核心能力

- **品牌必填 + 查询词可选**:只输入品牌名,自动基于行业生成 20-30 个查询词（4 类型:推荐 / 对比 / 痛点 / 决策）
- **8 节结构化报告**:摘要卡 / 品牌可见度分 / 查询词覆盖 / 竞品对比 / 引用源分析 / 优化机会 / 数据局限 / 行动清单 + 资金
- **4 维可见度子分**:被引用频次 / 推荐度 / 内容质量 / 平台覆盖
- **自动竞品对比**:基于品牌 + 行业推断 5-10 个竞品
- **数据时效分级**:🟢 < 6 月 / 🟡 6-12 月 / 🟠 1-2 年 / 🔴 > 2 年,硬指标 🟢+🟡 ≥ 80%
- **完整标签系统**:来源等级（🏛️📊📰🏪👤）+ 置信度（🟢🟡🔴）+ 推算依据 + 决策可执行性
- **14 条禁止项**:主语 3 + 内容 4 + 表达 4 + 数据 3
- **8 行业 × 4 类型查询词模板**:奶茶 / 咖啡 / 餐饮 / SaaS / 教育 / 旅游 / 电商 / 金融

## 适用场景

- "我的品牌在豆包/Kimi/文心/ChatGPT 里被提到多少"
- "AI 搜索里我的竞品排第几"
- "我应该发什么内容才能被 AI 引用"
- "哪些网站是 AI 反复引用的源头,要不要去那里发"

## 不适用

- 想要 SEO 排名报告（那是 SEO,不是 GEO）
- 想要真实跑 LLM 测品牌出现（v2.0 接 API key 模式）
- 海外英文市场（v2.0 规划）
- 行业不在 8 行业模板内（可手动输入 `category` 触发通用模板）

## 输入要求

| 字段 | 必填 | 说明 |
|---|---|---|
| `brand` | ✅ | 品牌名 / 域名 / 产品名 |
| `queries` | ⚪ | N 个目标查询词（可选,留空自动生成 20-30 个） |
| `category` | ⚪ | 行业/品类（辅助自动生成查询词） |
| `competitors` | ⚪ | 竞品列表（辅助对比） |

## 输出格式

- **类型**:Markdown 报告
- **大小**:50-150KB（8 节 + 数据分布表 + 优化机会清单）
- **保存位置**:当前工作目录的 `geo_report_<品牌>_<日期>.md`

## 8 节报告结构

| 节 | 内容 |
|---|---|
| 一 摘要卡 | verdict（🟢/🟡/🔴）+ 综合分（0-100）+ 3 句话结论 + 关键数字 |
| 二 品牌可见度分 | 综合分 + 4 维子分（被引用频次 / 推荐度 / 内容质量 / 平台覆盖） |
| 三 查询词覆盖 | 每个查询词的 AI 引用源 top 10 + 品牌出现标记 |
| 四 竞品对比 | 5-10 个竞品的可见度对比表 |
| 五 AI 引擎引用源分析 | top 20 URL / 域名 / 平台分布 |
| 六 优化机会清单 | 3 类（立即做 / 中期投入 / 长期建设）+ 4 维评估 |
| 七 数据局限 | 哪些引擎抓不到 + 置信度说明 + 偏差建议 |
| 八 行动清单 + 资金 | 3 大类资金分配 + 3-5 条红线 |

## ⚠️ 能力边界（重要）

v1.0 用 web_search 抓 AI 引用源:
- ✅ **覆盖**:Google AI Overview + Perplexity 引用基础（~40% 真实国内 GEO 信号）
- ❌ **不覆盖**:豆包 / Kimi / 文心一言 / 腾讯元宝 / 秘塔等国内 AI 引擎（它们是 SPA,内容不公开）
- 报告第 7 节"数据局限"明示这一点,不假装 100% 准确

## 跑批性能

- 单次跑批:N=30 查询词 × 5-10 个结果 = ~200-300 web_search 调用
- 数据时效硬指标:🟢+🟡 ≥ 80%,🔴 ≤ 10%
- 鲁棒性:10 场景（web_search 不可用 / 多源冲突 / 跨 LLM provider / token 截断等）
