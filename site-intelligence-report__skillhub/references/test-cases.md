# 测试用例与评分标准

3 个标准测试用例覆盖高/中/低数据丰富度，验证 skill 输出质量。

---

## 测试用例 1：北京西单大悦城 · 蜜雪冰城（高数据丰富度）

```json
{
  "brand": "蜜雪冰城",
  "address": "北京市西城区西单大悦城 B1 层 A-12",
  "city": "北京",
  "category": "奶茶",
  "expected_rent": 30000,
  "expected_area": 30
}
```

**预期**：

| 字段 | 难度 | 预期 |
|---|---|---|
| 摘要卡 verdict | 🟢 | 正常输出 |
| 商场整体客流 | 🟢 | 2024+ 数据 |
| 周边竞品 Top 5 | 🟡 | 至少 3 个真实门店 |
| 关店案例 | 🟢 | 至少 2 个 2024-2026 真实案例 |
| 政策风险 | 🟢 | 2024+ 新规可查 |
| 客群画像 | 🔴 | 写「未找到公开数据」|
| 财务测算 | 🟢 | 基于输入可算 |

**评估标准**：

- 10 节齐全 + 附录 A 触发正确 + 附录 B/C 齐全 + 免责声明
- 至少 6 个字段用真实搜索数据
- 🔴 字段正确写「未找到公开数据」
- 每个事实带来源链接
- 关店案例限定 2024-2026 + 同品类 + 同城市
- 报告头部数据时效分布表 🟢+🟡 ≥ 80%、🔴 ≤ 10%
- 关键数据点标来源等级 + 置信度 + 推算依据 + 决策可执行性
- 行动清单按 3 类分 + 4 维评估 + 3-5 条否决红线
- 3x3 财务敏感性矩阵 + 概率×影响风险矩阵 + 资金准备 3 大类

## 测试用例 2：成都春熙路某街铺 · 咖啡（二线城市热门商圈）

```json
{
  "brand": "未指定",
  "address": "成都市锦江区春熙路西段 88 号",
  "city": "成都",
  "category": "咖啡",
  "expected_rent": 20000,
  "expected_area": 40
}
```

**预期**：

| 字段 | 难度 | 预期 |
|---|---|---|
| 商圈名 | 🟢 | 春熙路 |
| 商场整体客流 | 🟡 | 部分数据 |
| 周边咖啡竞品 | 🟡 | 至少 2-3 个 |
| 关店案例 | 🟡 | 部分案例 |
| 政策风险 | 🟡 | 当地咖啡新规 |
| 客群画像 | 🔴 | 写「未找到公开数据」|
| 财务测算 | 🟢 | 基于输入可算 |

**评估标准**：

- 10 节齐全 + 附录齐全
- 至少 4 个字段用真实数据
- 街铺（非商场）的关店案例找法与测试 1 不同
- 同品类筛选（咖啡/奶茶店）正确
- 数据时效 🟢+🟡 ≥ 80% + 标签系统 + 3x3 + 概率×影响 + 行动清单 4 维 + 资金 3 大类

## 测试用例 3：某三线城市某街铺 · 快餐（低数据丰富度）

```json
{
  "brand": "张亮麻辣烫",
  "address": "湖南省衡阳市蒸湘区解放路 35 号",
  "city": "衡阳",
  "category": "快餐",
  "expected_rent": 8000,
  "expected_area": 50
}
```

**预期**：

| 字段 | 难度 | 预期 |
|---|---|---|
| 商圈名 | 🟡 | 可能需推断 |
| 商场整体客流 | 🔴 | 几乎无数据 |
| 周边快餐竞品 | 🔴 | 几乎无 |
| 关店案例 | 🔴 | 几乎无 |
| 政策风险 | 🟡 | 当地餐饮新规 |
| 客群画像 | 🔴 | 写「未找到公开数据」|
| 财务测算 | 🟢 | 基于输入可算 |

**评估标准**：

- 10 节齐全（即使大部分字段写「未找到公开数据」）
- 至少 2 个字段用真实数据（如全国性张亮麻辣烫新闻、当地政策）
- 不会硬编造数据
- 末尾「数据局限」明确说明三线城市数据稀缺
- 不阻塞报告生成
- 标签系统 + 资金 3 大类 + 风险矩阵均渲染（即使数据为空也给框架）

---

## 评分标准

| 评级 | 标准 |
|---|---|
| 🟢 优秀 | 10 节齐全 + 附录齐全、🟢+🟡 数据 ≥80%、🔴 正确处理、每条事实带引用 + 标签（来源+置信度+推算+决策可执行性）、3x3 + 概率×影响 + 行动清单 4 维 + 资金 3 大类 + 3-5 条否决红线全有 |
| 🟡 合格 | 10 节齐全 + 附录齐全、🟢+🟡 数据 ≥60%、🔴 正确处理、大部分事实带引用、3x3 + 概率×影响矩阵完整、行动清单按 3 类分 |
| 🔴 失败 | 10 节缺失、用模型记忆填充、跨品类污染、引用缺失、标签缺失、3x3/概率×影响未渲染、3 项以上硬约束不通过 |
