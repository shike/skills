# 报告范本

## 版本策略

仓库只保留**当前标准版**范本（v3），不保留迭代历史（v1/v2）。原因：
- v1/v2 的问题已在 v3 范本中修复（主语漂移、数据时效差、标签缺失等）
- 保留 v1/v2 容易让用户误以为它们是"可选风格"，实际是已知失败模式
- 每次 skill 升级会重写或新增范本，旧范本视为废弃

v3 范本 = v1.1.0 skill 的输出标准。

## 5 块必加规则

1. **数据时效分级**：报告头部 🟢🟡🟠🔴 分布表 + 📌历史事实/⏱️经营现状分类
2. **完整标签系统**：来源等级（🏛️📊📰🏪👤）+ 置信度（🟢🟡🔴）+ 推算依据 + 决策可执行性（✅⚠️❌）
3. **3x3 财务敏感性矩阵**：客单价 × 房租 × 客流 = 9 场景
4. **概率 × 影响 风险矩阵**：6 维度（拆迁/政策/竞品/客流/财务/品类适配）
5. **行动清单 + 资金准备**：4 维评估 + 3 大类（开业一次性/爬坡期/突发储备）

硬指标：🟢 + 🟡 ≥ 80%；🔴 过期数据 ≤ 10%。
