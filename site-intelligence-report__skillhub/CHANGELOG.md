## [1.1.1] - 2026-08-10

### 变更
- **重命名**：`site-intelligence-report` → `拓店选址尽调：基于公开数据与品类基准的财务三维评估`
- **description 重写**：从能力清单式改为"框架 + 范围"式，更适合 WorkBuddy 卡片展示
  - 旧：列 10 节 + 24 字段 + 5 块规则 + 零 API Key
  - 新：单地址 + 多地址对比 + 9 维度 + 6 品类基准
- **tags 升级**：从 4 个通用词（选址分析/拓店尽调/品牌调研/联网搜索）→ 8 个差异化词（选址尽调/拓店决策/商业分析/**品类基准**/**财务矩阵**/风险评估/联营加盟/盈亏平衡）
- **keywords 扩容**：从 7 个 → 18 个，新增"餐饮拓店/奶茶选址/咖啡选址/商场招商/街铺选址/盈亏平衡/回本周期/租金谈判/关店案例/餐饮尽调"等垂直搜索词

### 命名依据（用户偏好：工具书式 + 量化副标题）
- 《人月神话》《代码大全》风格：主标题简洁（业务动词+对象）+ 副标题说明方法
- 避免营销词："AI 速成/保姆级/震撼/3 天搞定"等
- 三个量化差异点：24 字段（结构化）+ 3×3 财务矩阵（方法论）+ 6 品类基准（差异化壁垒）
- 不用英文命名（WorkBuddy 中文用户为主）

### 不变
- `_meta.json` 的 `slug: site-intelligence-report`（stable id，跨平台引用保持稳定）
- `examples/` 报告内"主语锁定"声明中的 `site-intelligence-report`（技术性 stable id）
- 所有范本内容（pattern_checker 100% 通过）

## [1.1.0] - 2026-08-08

### 新增（vs v1.0.0）
- **Step 0.5 主语锁定**（Hard Constraint）：解析后第一件事锁定主品牌/品类/地址/客单价，财务模型与行动清单全部基于主品牌
- **Step 0.6 数据时效分级**（Hard Constraint）：🟢<6 月 / 🟡6-12 月 / 🟠1-2 年 / 🔴>2 年 四档，报告头部强制分布表
- **Step 2.5 财务反推 + Verdict 自动调整**：月净利 ≤ 0 或回本 > 24 月自动判 🔴
- **Step 2.5.1 3x3 财务敏感性矩阵**（Hard Constraint）：客单价 × 房租 × 客流 = 9 场景
- **Step 2.5.2 概率 × 影响 风险矩阵**（Hard Constraint）：6 维度（拆迁/政策/竞品/客流/财务/品类适配）
- **Step 2.7 完整标签系统**（Hard Constraint）：来源等级（🏛️📊📰🏪👤）+ 置信度（🟢🟡🔴）+ 推算依据 + 决策可执行性（✅⚠️❌）
- **Step 3.1 行动清单 4 维评估**：每条行动含 成本/收益/风险/决策可执行性
- **Step 3.2 资金准备 3 大类**（Hard Requirement）：开业一次性 60-70% / 爬坡期 15-20% / 突发储备 10-15%
- **Step 5 输出自检**（Hard Requirement）：A-H 八大类检查表，不通过处置规则明确
- **多地址对比模式**：2+ 地址输入触发，输出对比矩阵 + 综合推荐 + N 份精简报告
- **谈判话术（字段 24）**：基于公开房源 + 关店案例生成 ≥3 条话术
- **风险评分卡（字段 22）**：6 维度加权和 = 风险综合分
- **盈亏平衡日销量（字段 18）**：固定成本/(客单价-单位变动成本)
- **6 月现金流预测（字段 19）**：爬坡假设 30% → 100%
- **公开房源（字段 20）**：58/安居客 5-10 个，输出中位数/P25/P75
- **外卖月销（字段 21）**：竞品美团/饿了么数据
- **季节性指数（字段 23）**：6 品类 12 月季节性曲线
- **附录 C 决策深度分析 8 项**：C-1 品类适配 / C-2 差异化 / C-3 签约前法律核查（8 硬约束）/ C-4 历史经营 / C-5 位置战略 / C-6 个人资源 / C-7 退出止损 / C-8 风险对冲
- **鲁棒性 10 场景**：web_search 不可用 / 字段搜不到 / 多语言 / 跨 LLM provider / 单次搜索无效 / 多源冲突 / references 缺失 / examples 缺失 / 自然语言输入 / token 截断
- **3 个测试用例**：北京西单大悦城（高数据）/ 成都春熙路（中数据）/ 衡阳解放路（低数据）
- **2 份 v3 标准范本**：苏州泰华·蜜雪冰城（735 行）/ 成都春熙路·咖啡店（590 行）

### 变更
- 输入支持自然语言 + JSON 双格式
- Fallback 规则表：缺品牌/地址/品类/租金/面积都有兜底值

### 修复

## [1.0.0] - 2026-08-07

初版（已废弃，未在仓库留档）

基础能力：
- 10 节结构化选址分析报告框架
- 24 字段定义（基础版，无 3x3 矩阵 / 概率影响矩阵 / 资金 3 大类）
- 自然语言 + JSON 输入
- 1 个测试用例

已知问题：
- 主语未严格锁定，存在"反客为主"风险（霸王茶姬等竞品对标算入主财务模型）
- 无数据时效分级
- 无概率影响矩阵（用加权平均打分，风险粒度不够）
- 行动清单无 4 维评估
- 无资金准备章节
- 无 Step 5 输出自检

→ v1.1.0 解决上述全部问题

## 版本号约定

- **MAJOR**：主语结构变更、字段重设计、API 不兼容
- **MINOR**：新增 Hard Constraint、新增字段、新增范本
- **PATCH**：文档修订、bug fix、阈值微调

## 数据时效同步

- **SKILL.md 流程**：每年 Q1 review，重大变化升 MINOR
- **category-baseline.md**：每年 Q1 基于上年度 CCFA/美团/艾瑞报告更新，与 skill version 联动
- **examples/**：每次 MINOR 版本升级至少补 1 份新范本
