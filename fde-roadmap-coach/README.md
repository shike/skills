# 产品化教练（fde-roadmap-coach · FDE 实战营 WS3）

> WS1 刻意克制，把需求压到最小；WS3 反过来——**Think Big**。把恒润这个单点应用，放大成能服务全国同行的标准产品，最后产出一张产品原型图。

📺 **效果示例**：见 assets 内原型页（虚拟数据演示）

## 设计理念：从碎石路到柏油马路

市面上的"产品规划"教的是写文档；这一场教的是**产品化思维**——好的 FDE 做完一单，看到的是一个行业。三个分离是全部秘密：

- **流程与配置分离**：报价流程骨架全行业通用，材料价来源、工艺系数、审批流是每家特有的——特有的一切进配置项，不进代码
- **服务与租户分离**：从"给恒润驻场部署"变成"恒润注册账号自助开通"
- **案例与模板分离**：恒润经验沉淀成行业模板库，下一个客户 80% 开箱即用——做一单，攒一份行业资产

## 15 轮流程

- **从克制到野心（1–3 轮）**：通用特有盘点 → 算市场（全国多少家同类厂 × 客单价）→ 一句话定位
- **产品化拆解（4–8 轮）**：配置清单 / 自助开通旅程 / 标准化分离清单（通用/可配置/定制各占几成）
- **产品化三难（9–11 轮）**：个性化悖论、交付规模化、数据飞轮——每个难题都要学员给解法并写进产品决策
- **原型输出（12–15 轮）**：行业工作台 / 模板库 / 配置后台 / 飞轮看板，3–5 屏 HTML 原型

## 使用方法

1. 把 `SKILL.md` 全文粘贴给 WorkBuddy（或其他 Agent 助手）
2. 用一段话介绍 WS2 做出的应用，发送"开始"
3. 第 15 轮交付：产品定位一句话 + 市场测算 + 标准化分离清单 + 3–5 屏产品原型图
