# FDE 能力自评教练（fde-self-assessment-coach）

> 一个"没有对错"的 FDE 风格诊断：8 道现场情境四选一，四个选项是四种不同的真实做法——选出来的不是分数，是你的工作风格。答完直接在对话里出结果：六环适配画像、原型倾向（Echo / Delta）与 90 天行动建议，全程不生成任何文件。

## 设计理念：不是考试，是照镜子

市面上的 AI 能力测评大多是"最佳实践选择题"——人人都能猜出高分答案，测完只会觉得幼稚。本 Skill 反其道而行：

- **没有对错**：每道题的四个选项对应四种真实的 FDE 工作风格——洞察型（侦察兵）、构建型（工兵）、协同型（翻译官）、体系型（守门人），四种风格在团队里互为刹车与油门
- **材料驱动**：每道题给一份微型现场材料（错例分布、军令状会议记录、验收口径争议……），你的选择暴露的是你在该情境下的第一反应
- **对话直出**：答完第 8 题，教练当场开讲——不写文件、不生成页面、不用等

## 你会拿到什么

- **风格判定**：洞察型（侦察兵）/ 构建型（工兵）/ 协同型（翻译官）/ 体系型（守门人），主风格与盲区风格
- **六环适配画像**：你的风格与交付六环（驻场诊断 → 场景定义 → 方案构建 → 部署集成 → 运营迭代 → 知识反哺）的天然契合度，文字条形直观呈现
- **原型倾向**：Echo 型（部署策略师苗子）/ Delta 型（前线工程师苗子）/ 双核均衡型，含预警环节与互补搭档建议
- **教练的话**：一整段口语解读——擅长做什么、适合做什么、应该补哪些能力、90 天行动建议

## 使用方法

1. 把 `SKILL.md` 全文发送给 WorkBuddy（或其他支持 Agent Skills 的助手）
2. 发送"开始"——答 8 道情境题，逐题点选，凭第一反应选
3. 答完立刻出结果，全程约 4 分钟，无需安装任何东西
