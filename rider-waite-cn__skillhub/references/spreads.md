# 18 牌阵定义

> **版本**: v1.0.0
> **地位**: 本 skill 唯一牌阵事实源。所有 LLM 解读必须按本文件定义每个位置。
> **使用方式**: 按牌阵名调用 → 按位置表渲染解读。

---

## I. 通用类（5 个）

### 1. 单张牌（Single Card）— `single`

- **牌数**: 1
- **用途**: 是/否、每日一抽、快速指引
- **位置**:
  - 位置 1: 答案
- **选牌规则**: 摊出 5-7 张[背]，用户选 1 张
- **解读顺序**: 1
- **适用**: 日常运势、单一疑问、快速决策参考
- **特殊**: intensity 固定为 `light`

### 2. 三张牌（Three Cards）— `three-cards`

- **牌数**: 3
- **用途**: 过去/现在/未来
- **位置**:
  - 位置 1: 过去（成因）
  - 位置 2: 现在（现状）
  - 位置 3: 未来（趋势）
- **选牌规则**: 摊出 6-9 张[背]，用户选 3 张
- **解读顺序**: 1 → 2 → 3

### 3. 时间流（Time Flow）— `time-flow`

- **牌数**: 3
- **用途**: 平行时间线预测
- **位置**:
  - 位置 1: 过去
  - 位置 2: 现在
  - 位置 3: 未来
- **选牌规则**: 同三张牌
- **解读顺序**: 1 → 2 → 3
- **与三张牌差异**: 时间流强调"时间向度上的展开"，三张牌强调"原因-现状-结果"；解读叙事方向略不同

### 4. 圣三角（Holy Triangle）— `holy-triangle`

- **牌数**: 3
- **用途**: 起因/现状/建议
- **位置**:
  - 位置 1: 起因（成因）
  - 位置 2: 现状（问题核心）
  - 位置 3: 建议（如何应对）
- **选牌规则**: 摊出 6-9 张[背]，用户选 3 张
- **解读顺序**: 1 → 2 → 3
- **特点**: 不预测未来，给行动方向

### 5. 四元素（Four Elements）— `four-elements`

- **牌数**: 4
- **用途: 多角度审视单一问题
- **位置**:
  - 位置 1: 火（行动 / 激情 / 推动力）
  - 位置 2: 水（情感 / 直觉 / 关系）
  - 位置 3: 风（思想 / 沟通 / 视角）
  - 位置 4: 土（物质 / 实际 / 结果）
- **选牌规则**: 摊出 8-10 张[背]，用户选 4 张
- **解读顺序**: 火 → 水 → 风 → 土

## II. 深度类（5 个）

### 6. 凯尔特十字（Celtic Cross）— `celtic-cross`

- **牌数**: 10
- **用途**: 综合分析
- **位置**（前 6 张构成十字，后 4 张立柱）:
  - 位置 1: 现状（核心）
  - 位置 2: 挑战（阻碍）
  - 位置 3: 过去（基础 / 根源）
  - 位置 4: 近期未来（即将到来）
  - 位置 5: 潜意识（内心）
  - 位置 6: 近期过去（背景）
  - 位置 7: 自我（提问者）
  - 位置 8: 环境（周围）
  - 位置 9: 希望 / 恐惧
  - 位置 10: 最终结果
- **选牌规则**: 摊出 12-15 张[背]，用户选 10 张
- **解读顺序**: 1 → 2 → ... → 10
- **特点**: intensity 默认 `deep`，解读长度 1500-3000 字
- **塔罗师诫命**: 不预测最终结果的具体事件，给"趋势 + 行动方向"

### 7. 六芒星（Hexagram / Star of David）— `hexagram`

- **牌数**: 7
- **用途**: 深度预测
- **位置**:
  - 位置 1: 过去
  - 位置 2: 现在
  - 位置 3: 未来
  - 位置 4: 你的对策
  - 位置 5: 周遭状况
  - 位置 6: 你的态度 / 希望 / 恐惧
  - 位置 7: 最终结果
- **选牌规则**: 摊出 10-12 张[背]，用户选 7 张
- **解读顺序**: 1 → 2 → 3 → 4 → 5 → 6 → 7
- **特点**: intensity 推荐 `deep`

### 8. 十二宫（Horoscope）— `horoscope`

- **牌数**: 12
- **用途**: 12 人生领域全面分析
- **位置**（对应黄道十二宫）:
  - 位置 1（白羊）: 自我 / 外貌
  - 位置 2（金牛）: 财务 / 价值观
  - 位置 3（双子）: 沟通 / 学习
  - 位置 4（巨蟹）: 家庭 / 根源
  - 位置 5（狮子）: 恋爱 / 创造力
  - 位置 6（处女）: 工作 / 健康
  - 位置 7（天秤）: 关系 / 合作
  - 位置 8（天蝎）: 共有财务 / 性 / 转化
  - 位置 9（射手）: 目标 / 远方 / 信仰
  - 位置 10（摩羯）: 事业 / 地位
  - 位置 11（水瓶）: 朋友 / 群体 / 理想
  - 位置 12（双鱼）: 隐藏 / 潜意识 / 精神
- **选牌规则**: 摊出 15-18 张[背]，用户选 12 张
- **解读顺序**: 1 → 12
- **特点**: intensity 必须 `deep`；建议每年 / 每月一次
- **塔罗师诫命**: 不预测具体运势，呈现"领域状态"

### 9. 生命之树（Tree of Life）— `tree-of-life`

- **牌数**: 10
- **用途**: 深度探索、长期功课
- **位置**（对应卡巴拉生命之树 10 球体）:
  - 位置 1: 王冠（最高理念 / 目的）
  - 位置 2: 智慧（创造力）
  - 位置 3: 理解（现实中的智慧）
  - 位置 4: 慈悲（机会 / 积极）
  - 位置 5: 严厉（冲突）
  - 位置 6: 美（个性）
  - 位置 7: 胜利（吸引 / 喜爱）
  - 位置 8: 荣耀（表达 / 沟通）
  - 位置 9: 基础（习惯）
  - 位置 10: 王国（现状）
- **选牌规则**: 摊出 12-15 张[背]，用户选 10 张
- **解读顺序**: 现状（10）→ 习惯（9）→ 表达（8）→ ... → 王冠（1）
- **特点**: intensity `deep`；与卡巴拉 / 赫尔墨斯主义相关

### 10. 周运势（Weekly）— `weekly`

- **牌数**: 7
- **用途**: 一周运势
- **位置**:
  - 位置 1: 周一
  - 位置 2: 周二
  - 位置 3: 周三
  - 位置 4: 周四
  - 位置 5: 周五
  - 位置 6: 周六
  - 位置 7: 周日
- **选牌规则**: 摊出 9-12 张[背]，用户选 7 张
- **解读顺序**: 1 → 7
- **特点**: intensity 建议 `light`；按时间线呈现趋势

## III. 感情类（5 个）

### 11. 二选一（Two Choices）— `two-choices`

- **牌数**: 5
- **用途**: A vs B 抉择
- **位置**:
  - 位置 1: 现状
  - 位置 2: 选 A 的结果
  - 位置 3: 选 B 的结果
  - 位置 4: 选 A 的关键挑战
  - 位置 5: 选 B 的关键挑战
- **选牌规则**: 摊出 7-10 张[背]，用户选 5 张
- **解读顺序**: 1 → 4 → 2 → 5 → 3
- **特点**: 塔罗师诫命——不替用户做决定

### 12. 维纳斯之爱（Venus Love）— `venus`

- **牌数**: 8
- **用途**: 两性关系深度
- **位置**:
  - 位置 1: 你的看法
  - 位置 2: 对方的看法
  - 位置 3: 你对对方的影响
  - 位置 4: 对方对你的影响
  - 位置 5: 障碍
  - 位置 6: 关系结果
  - 位置 7: 未来你对这件事的回忆
  - 位置 8: 未来对方的想法
- **选牌规则**: 摊出 10-13 张[背]，用户选 8 张
- **解读顺序**: 1-4 → 7-8 → 5-6
- **特点**: 仅小阿卡纳；intensity `standard` 或 `deep`

### 13. 吉普赛十字（Gypsy Cross）— `gypsy-cross`

- **牌数**: 5
- **用途**: 爱情专项
- **位置**:
  - 位置 1: 你的心态
  - 位置 2: 你的现状
  - 位置 3: 你采取的举措
  - 位置 4: 周遭环境
  - 位置 5: 关系未来
- **选牌规则**: 摊出 7-9 张[背]，用户选 5 张
- **解读顺序**: 1 → 2 → 3 → 4 → 5
- **特点**: 仅大阿卡纳

### 14. 情人复合（Lovers Reunion）— `lovers-reunion`

- **牌数**: 5
- **用途**: 分手后复合判断
- **位置**:
  - 位置 1: 你的状态
  - 位置 2: 对方的状态
  - 位置 3: 复合的潜在可能
  - 位置 4: 复合的阻碍
  - 位置 5: 复合的最终结果
- **选牌规则**: 摊出 7-9 张[背]，用户选 5 张
- **解读顺序**: 1 → 2 → 3 → 4 → 5
- **特点**: 塔罗师诫命——不替用户决定是否复合

### 15. 灵感对应（Soulmate Response）— `soulmate`

- **牌数**: 5
- **用途**: 双向情感互动
- **位置**:
  - 位置 1: 你的能量
  - 位置 2: 对方的能量
  - 位置 3: 情感联接
  - 位置 4: 当前互动
  - 位置 5: 互动走向
- **选牌规则**: 摊出 7-9 张[背]，用户选 5 张
- **解读顺序**: 1 → 2 → 3 → 4 → 5
- **特点**: 适合暧昧 / 关系观察期

### 16. 寻找对象（Find Soulmate）— `find-soulmate`

- **牌数**: 5
- **用途**: 单身人士 / 意中人画像
- **位置**:
  - 位置 1: 你目前的状态
  - 位置 2: 你希望的对象
  - 位置 3: 你不喜欢的对象
  - 位置 4: 该采取的行动
  - 位置 5: 未来的发展
- **选牌规则**: 摊出 7-9 张[背]，用户选 5 张
- **解读顺序**: 1 → 2 → 3 → 4 → 5
- **特点**: 适合长期单身 / 重新开始

## IV. 自我探索类（2 个）

### 17. 身心灵（Mind-Body-Spirit）— `mind-body-spirit`

- **牌数**: 3
- **用途: 自我探索
- **位置**:
  - 位置 1: 身（身体 / 行动）
  - 位置 2: 心（情感 / 关系）
  - 位置 3: 灵（精神 / 意义）
- **选牌规则**: 摊出 6-9 张[背]，用户选 3 张
- **解读顺序**: 身 → 心 → 灵
- **特点**: 向内寻求答案，不预测外部

---

## V. 事业类（1 个）

### 18. 财富之树（Tree of Wealth）— `tree-of-wealth`

- **牌数**: 5
- **用途**: 事业 / 财运
- **位置**:
  - 位置 1: 事业现状
  - 位置 2: 资源 / 机会
  - 位置 3: 阻碍
  - 位置 4: 行动建议
  - 位置 5: 3-6 个月趋势
- **选牌规则**: 摊出 7-9 张[背]，用户选 5 张
- **解读顺序**: 1 → 2 → 3 → 4 → 5
- **塔罗师诫命**: 不预测具体金额、不推荐投资标的

## VII. 牌阵选用决策树

LLM 在解析用户问题后，按以下顺序推断 spread：

```
1. 用户明确说牌阵名 → 用用户指定的
2. 用户问"今天/是/否" → single
3. 用户问"过去现在未来" → three-cards 或 time-flow
4. 用户问"原因/现状/怎么办" → holy-triangle
5. 用户纠结 A vs B → two-choices
6. 用户说"全面/深度/综合" → celtic-cross
7. 用户问"未来/最终结果" → hexagram
8. 用户问"年/月运势" → horoscope
9. 用户问"事业/财运" → tree-of-wealth
10. 用户问"感情/爱情" → 看细分：
    - 双向分析 → venus
    - 爱情专项 → gypsy-cross
    - 复合 → lovers-reunion
    - 暧昧观察 → soulmate
    - 单身 → find-soulmate
11. 用户问"自己/内心" → mind-body-spirit 或 four-elements
12. 用户问"下周/这周" → weekly
13. 用户没说明 → holy-triangle（最安全默认）
```
