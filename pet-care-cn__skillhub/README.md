# 宠物照护咨询 (pet-care-cn)

> **v2.0 已发布**。本文件是项目规划与设计文档,不是最终 SKILL.md。
> 落地节奏见 [§ 7 版本路线图](#7-版本路线图)。

## 1. Skill 定位

面向**养宠用户**的**结构化实用咨询**框架:用户问具体照护问题,AI 按预设结构给出可执行建议。

- **不替代兽医**:任何症状判断、诊断、用药剂量 → 硬转介线下兽医
- **不替代行为学家**:严重行为问题(持续攻击、严重分离焦虑)→ 转介专业训练师
- **不替代营养师**:疾病处方粮/特殊医学配方 → 转介兽医营养师
- **v2.0 异宠强转诊**:龟/蛇/蜥蜴/雪貂/刺猬/龙猫/鹦鹉/蜜袋鼯 → 任何异常直接异宠专科

## 2. 量化差异点(工具书式命名的核心)

| 维度 | 数量 | 说明 |
|---|---|---|
| 主题 | **6** | 饮食 / 驱虫与疫苗 / 绝育与生育 / 行为与训练 / 新宠到家 / 老年照护 |
| 常见宠物物种 | **5** | 猫 / 狗 / 兔 / 鸟 / 鼠 |
| 异宠物种(v2.0) | **8** | 龟 / 蛇 / 蜥蜴 / 雪貂 / 刺猬 / 龙猫 / 大型鹦鹉 / 蜜袋鼯 |
| 物种合计(v2.0) | **13** | 5 常见 + 8 异宠 |
| 月龄段 | **3** | 幼(<1 岁) / 成(1-7 岁) / 老(>7 岁) |
| 常见宠物细分场景 | **6 × 5 × 3 = 90** | 87 实质 + 3 占位,每场景预设回答模板 |
| 异宠细分场景(v2.0) | **8 × 1 = 8** | 每物种 1 通用模板(简化版,强转诊) |
| **模板总数** | **25** | 17 常见 + 8 异宠 |

**v2.0 异宠为什么简化版**:
- 异宠物种差异极大(龟的饲养和蛇完全不同),做完整 6×3=18 范例量太大
- 异宠医疗资源稀缺,主人自己操作风险高,**更倾向转介**
- 异宠寿命长(龟 50+ 年,鹦鹉 80 年),"幼/成/老"分段意义小
- 用户查询异宠的 80% 场景是"我家 XXX 怎么了/能养吗",基础识别 + 强转诊就够

## 3. 输入设计(input_schema)

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `species` | ✅ | enum(13) | 5 常见 + 8 异宠(见 § 2) |
| `topic` | ✅ | enum(6) | diet / dv / neuter / beh / arrival / senior-care |
| `age_stage` | ✅ | enum(3) | junior / adult / senior(异宠可填 `all-age` 简化) |
| `question` | ✅ | string | 用户原话 |
| `context` | ❌ | string? | 品种 / 体重 / 已确诊疾病 / 已用药物等 |
| `images` | ❌ | array? | v1.1+ 多模态,1-5 张图片 |
| `session_id` | ❌ | string? | v1.2+ 多轮对话,继承上下文 |
| `turn_index` | ❌ | int? | v1.2+,本轮在会话中的位置 |

**Fallback 规则**(沿用选址风格):

| 字段缺失 | 处理 |
|---|---|
| `species` | LLM 反问 1 次,异宠也要明确 8 类之一(不同物种饲养完全不同) |
| `topic` | LLM 基于 `question` 关键词归类,归类不确定则反问 |
| `age_stage` | 用户月龄未提则按体重/品种推算;推算失败默认 `adult`;异宠可填 `all-age` |
| `context` | 完全可选,缺失不阻塞 |

## 4. 输出结构(6 节固定)

1. **场景定位**:用 1 句话说清"你问的是 X 物种 Y 月龄 Z 主题"
2. **核心建议**:3-5 条可执行清单(最多)
3. **关键时点/参数**:数字表(月龄对应剂量、驱虫频率等)
4. **常见误区**:2-3 条"不要做 X"
5. **风险信号**:哪些情况必须立即就医
6. **兽医转介触发器**:本回答在 N 种情况下不构成医疗建议(异宠强转诊)

输出字数参考:
- 极简:200-400 字(快问快答)
- 标准:600-1200 字(默认)
- 深度:1500-2500 字(复杂场景,如老年照护)
- 异宠:400-800 字(简化版,强转诊话术占主)

## 5. 硬约束(9 条顶部诫命,违反则输出作废)

1. **不诊断**:看到「我家猫不吃东西/呕吐/便血」等任何症状关键词,首段必须先转介兽医
2. **不开药**:不推荐任何商品名药物剂量,只给"成分类别 + 建议就医"
3. **不替代训练师**:严重行为问题(持续攻击、自残、严重分离焦虑)转介
4. **不替代兽医安乐决策**:临终关怀只引导与兽医讨论,不做判断
5. **不画大饼**:不预测"这样做一定能治好",只给"概率与建议"
6. **不老调重弹**:每次回答不照抄通用模板,基于 `context` 调整
7. **不替代异宠专科** (v2.0):异宠任何异常直接异宠/禽类专科
8. **不推荐具体商品**:不点名品牌药物/猫粮/医院
9. **不遗忘隐私**:用户问题/宠物信息不写入永久记忆

## 物种特异点累计(全 25 模板)

### 5 类常见宠物
- **猫**:乳糖不耐、24h 不食=脂肪肝、公猫尿闭 24h 急症、多饮多尿=肾/甲亢/糖尿病、英短 HCM 高发
- **狗**:大型犬 12-18 月绝育(防髋关节)、胃扭转急症、2-3% 体重日食量、MDR1 基因(柯利犬)
- **兔**:提草 80% 必主粮、不排便=GI 停滞急症、母兔 60-80% 子宫腺癌风险
- **鸟**:不常规内驱、雏鸟 30-35℃ 保温、嗉囊停滞急症、不"绝育"改环境管理
- **鼠**:仓鼠必须独居(任何年龄)、鼠类不推荐绝育(麻醉致死率高)、湿尾症急症、豚鼠需维 C 补充

### 8 类异宠(v2.0+)
- **龟**:UVB 灯必装、玻璃阻挡 UVB、温度梯度(晒点 32-38℃ / 冷区 24-28℃)、不排酸=结石信号
- **蛇**:温控器必装、食物大小不超过蛇体最粗处、拒食>2 月就医、蜕皮不全=湿度问题
- **蜥蜴**:UVB 每 6-12 月换新、物种饮食分化极大(鬃狮/绿鬣蜥偏植食、豹纹守宫肉食)、MBD 不可逆
- **雪貂**:必须绝育(否则雌激素中毒)、胰岛素瘤高发、高蛋白低碳、笼内活动 ≥4 h/日
- **刺猬**:温控 24-29℃、低脂高蛋白、WHS(Wobbly Hedgehog Syndrome)不可治愈、油粮致肝病
- **龙猫**:沙浴每日 10 分钟、室温 ≤25℃(中暑致命)、牙齿终身生长需磨牙、群居(单只抑郁)
- **大型鹦鹉**:禁烟/禁清新剂/禁 Teflon 高温烟雾(30 分钟内死亡)、日陪伴 ≥2-4h、防啄羽心理病
- **蜜袋鼯**:群居(单只自我损伤)、高蛋白低脂、牙齿问题多、公蜜袋鼯去势需专业、需大笼
