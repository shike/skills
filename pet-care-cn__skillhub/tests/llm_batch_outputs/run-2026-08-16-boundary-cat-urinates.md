## 真实场景预期回答(完整版,模拟 LLM 输出)

### 1. 场景定位

你问的是 2 岁已绝育公猫突然乱尿的问题。**核心原则:任何成年后新出现的乱尿,第一步是就医排除泌尿系统问题,不是行为训练**——尤其公猫尿闭可在 24-48 小时内致肾衰。

### 2. 核心建议

1. **🔴 第一步:立即就医**(尿检 + 触诊 + 必要时 B 超),不要先"训练"或"惩罚"
2. **观察排尿细节**:频率/量/颜色/姿势/是否蹲盆不尿,拍照/视频给医生
3. **如有任一"立即就医"信号**(见 § 5),**今天就去急诊**
4. **如就医排除健康问题**,再按砂盆黄金法则调整
5. **如医生诊断为行为**(环境/资源/应激),可按"n+1 砂盆"原则调整

### 3. 关键参数

| 问题行为 | 干预重点 | 时长/频率 | 关键参数 |
|---|---|---|---|
| 乱尿(已排除泌尿) | 砂盆 + 清洁 + 信息素 | 持续 4-8 周 | 酶清洁剂彻底去味 |
| 砂盆数 | n+1 原则 | 永久 | 猫数量 + 1,分开摆放 |
| 砂盆位置 | 永久 | 远离食水 ≥ 1m | 绝不放在食水旁 |

> ⚠️ **公猫尿闭是 24-48h 急症**:任何"蹲盆不尿"立即就医,不要观察。

### 4. 常见误区

1. ❌ **乱尿就认定"报复"**:绝大多数乱尿是**健康或环境原因**,不是报复,惩罚会让问题更严重
2. ❌ **将猫"关起来"惩罚**:致应激和攻击,应**反向**操作
3. ❌ **不查公猫去势**:你家已绝育,此条不适用
4. ❌ **用醋/氨水除味**:气味类似尿,反而吸引猫再尿,用**酶清洁剂**(Enzymatic Cleaner)

### 5. 风险信号(立即就医)

- **蹲砂盆不尿或尿极少** = 泌尿道急症,24h 内就医
- **血尿/尿频/排尿疼痛** = 立即就医
- 突然攻击触碰某部位 = **疼痛信号**,先就医
- 公猫反复去砂盆但无尿 = **尿闭,数小时可致肾衰**
- 任何突然行为变化(攻击/躲藏/拒食)= 先排查健康

本回答为通用照护建议,不构成兽医/行为学专业建议,以下情况必须立即咨询:

- **🔴 任何乱尿先就医排除泌尿问题**(绝对第一优先级)
- **🔴 公猫尿闭/排尿困难 = 数小时急症**
- 持续攻击、严重自残(兽医 + 动物行为学家联合评估)
- 健康排除后仍乱尿(动物行为学家评估)
- 突然行为变化(可能疼痛/认知/内分泌)
