## [2.0.0] - 2026-08-16

### 🎉 v2.0 异宠支持(8 物种简化版)

**13 物种覆盖(5 常见 + 8 异宠),25 模板,8 异宠通用范例,强转诊策略**。

### 新增
- **`references/exotic-pets.md`**(7.4 KB,160 行)
  - 8 异宠寿命/急症/红线速查表
  - 简化版设计决策理由(每物种 1 通用模板)
  - 8 异宠基础信息(温度/湿度/食性/群居/寿命)
  - 强转诊话术与异宠医疗资源指引
- **8 个异宠模板**(`references/qa-templates/exotic-*.md`)
  - `exotic-turtle.md`(龟:UVB + 温度梯度 + 水质 + 补钙)
  - `exotic-snake.md`(蛇:温控 + 湿度 + 食物大小 + 拒食)
  - `exotic-lizard.md`(蜥蜴:UVB 必装 + 温度梯度 + 物种特异饮食)
  - `exotic-ferret.md`(雪貂:高蛋白 + 绝育必要 + 胰岛素瘤)
  - `exotic-hedgehog.md`(刺猬:温控 + 油粮 + WHS 综合征)
  - `exotic-chinchilla.md`(龙猫:沙浴 + 低温 + 牙齿 + 群居)
  - `exotic-parrot-large.md`(大型鹦鹉:空气红线 + 高陪伴 + 心理健康)
  - `exotic-sugar-glider.md`(蜜袋鼯:群居 + 蛋白 + 牙齿 + 自我损伤)
- **`examples/example-06-exotic-turtle.md`**:龟拒食 P0 案例
- **SKILL.md 扩展**:
  - species enum 5→13 选 1
  - 诫命 7 新增"不替代异宠专科"
  - safe-boundary.md § 8.9 异宠强转诊话术
- **`tests/pattern_checker.py` 升级**:
  - 模板数 17→25
  - 异宠模板阈值放宽(急症 ≥2 / 兽医 ≥2,因为简版内容短)
  - 必填文件加 8 异宠模板 + exotic-pets.md + example-06
  - **结果:198 pass / 0 warn / 0 fail**

### 决策
- **简化版 vs 完整版**:异宠物种差异极大(龟 vs 蛇 vs 鹦鹉完全不同),做完整 6×3=18 范例量太大;医疗资源稀缺强转诊策略更合理
- **强转诊策略**:异宠不展开 6 节大循环,P0 直接简版转诊(避免延误)
- **8 异宠不细分月龄**:异宠寿命长(龟 50+ / 鹦鹉 80 年),"幼/成/老"分段意义小,统一"全龄"
- **worker 失败重试**:snake/lizard 第一次重做成功(1 worker 1 模板 + 极简 brief)
- **6 worker 失败 → 5 worker 成功**(snake/lizard 重做)

### 命名决策
- 主标沿用工具书式 + 量化副标题
- 新版副标:**"6 主题 × 5 类常见宠物 + 8 类异宠结构化问答"**

### 物种特异点全覆盖
- 猫:24h 不食=脂肪肝、公猫尿闭 24h 急症、多饮多尿=肾/甲亢/糖尿病、英短 HCM 高发
- 狗:大型犬 12-18 月绝育(防髋关节)、胃扭转急症、2-3% 体重日食量、MDR1 基因(柯利犬)

- 鸟:不常规内驱、雏鸟 30-35℃ 保温、嗉囊停滞急症、不"绝育"改环境管理
- 鼠:仓鼠必须独居(任何年龄)、鼠类不推荐绝育(麻醉致死率高)、湿尾症急症、豚鼠需维 C 补充

### 质量保证
- 5 worker 并行做主题 2-6,我主进程做主题 1(饮食)做样本
- 1 worker 失败重做(老年照护第一次未产出文件,精简 brief 后重做成功)
- 所有 worker 自查硬约束通过(不诊断/不开药/不替代训练师/不写营销词/不渲染悲伤)

### 已知边界
- 苯丙醇胺(US/欧洲常见处方药成分名)出现 1 处,已标"遵医嘱"
- beh-senior 4 处"评估安乐",写法"评估时机+转介",未越界做判断

### 风险
- 医疗边界是最大挑战(看似简单的"我家猫不吃东西"可能没事也可能猫传腹)
- 物种间寿命差异巨大(鼠 1.5 岁就算老,鸟 15 年可能还算青年)
