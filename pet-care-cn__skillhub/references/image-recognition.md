# 图片识别工作流(多模态支持,v1.1+)

> **版本**:v1.1
> **作用**:处理用户发宠物图片(皮肤病/外伤/异常)的辅助识别流程
> **不替代兽医**:本 skill 只描述"看到了什么"并分级,不诊断疾病名,不推荐药物

## 1. 适用范围

**支持识别**:
- 皮肤病变(红肿/脱毛/结痂/分泌物/异常颜色)
- 外伤(出血/肿胀/开放性伤口/骨折迹象)
- 眼/耳/口/鼻/肛门/外生殖器异常(分泌物/红肿/异物)
- 行为可见迹象(跛行/姿态异常/明显疼痛表情)
- 物种识别(确认是猫/狗/兔/鸟/鼠)

**不适用**:
- 体内疾病诊断(需要兽医器械)
- 血液/粪便/尿液检查(需要化验)
- X 光/CT/MRI 影像解读(需要专业兽医影像学)
- 心理/行为问题深度分析(用 beh 模板)

## 2. 输入扩展

```yaml
species: cat | dog | rabbit | bird | rodent  # 必填
question: string?  # 选填,用户文字问题
context: string?   # 选填,品种/年龄等
images:
  - id: img-1
    src: <base64 | url>  # 必填
    angle: 顶视 | 侧视 | 近距离 | 全身  # 选填
  - id: img-2
    ...
```

**图片数量**:1-5 张(超出提示精简)
**图片格式**:JPG/PNG/WEBP,最大 5MB/张
**图片限制**:本 skill 不存储图片,处理后立即丢弃

## 3. 识别流程(3 步)

### Step 1:图片质量检查(前置)

| 检查项 | 通过条件 | 不通过处理 |
|---|---|---|
| 清晰度 | 主体可辨认,无严重模糊 | 提示"图片模糊,请重拍" |
| 角度 | 目标部位可见 | 提示"角度问题,请重拍" |
| 光线 | 足够看清细节(无严重逆光/过暗) | 提示"光线不足,请在明亮处重拍" |
| 主体 | 是 5 类常见宠物之一 | 礼貌说明"本 skill 仅识别宠物" |
| 部位 | 病变/外伤部位可见 | 提示"请拍到异常部位" |

**通过率低时**:不强行判断,要求重拍(避免误诊)。

### Step 2:视觉描述(只描述,不诊断)

**原则**:
- 只描述"看到了什么",不写"这是 X 病"
- 描述具体可见细节(颜色/位置/范围/程度)
- 描述严重度(轻微/中等/严重)
- 不用医学术语(猫癣/湿疹/皮炎等)

**描述模板**:
```
部位: <具体位置>
外观: <颜色/形状/范围>
程度: <轻微/中等/严重>
特征: <分泌物/出血/结痂/肿胀 等>
```

**反例**:
- ❌ "这是猫癣" → 自我诊断
- ✅ "看到 [部位] 有 [圆形脱毛区/皮屑/边缘清晰]" → 只描述

### Step 3:风险分级 + 建议

| 等级 | 视觉特征 | 建议 |
|---|---|---|
| 🔴 **P0 立即就医** | 开放性出血 / 明显骨折 / 严重肿胀 / 呼吸异常 / 中毒迹象 / 急性瘫痪 | **立即急诊**,本 skill 不展开,直接转介 |
| 🟡 **P1 24-48h 就医** | 皮肤病变(红/肿/脱毛/结痂) / 中度外伤 / 持续分泌物 / 跛行 / 食欲不振伴随 | 24-48h 内就医,本 skill 给基础照护建议 |
| 🟢 **P2 观察** | 轻度抓痕 / 季节性掉毛 / 行为微变 / 食欲轻微下降 | 观察 3-5 天,持续则升级为 P1 |

**多图片**:取最高风险等级作为整体建议

## 4. 跨主题衔接(图片 + 模板)

图片识别完成后,基于风险等级,加载对应模板:

| 风险 | 加载模板 | 输出调整 |
|---|---|---|
| 🔴 P0 | 不加载模板 | 首段直接转介急诊,不做模板填充 |
| 🟡 P1 | 加载对应主题模板 | 在"风险信号"中加图片描述,在"兽医转介触发器"中显式提"医生会看图片/检查" |
| 🟢 P2 | 加载对应主题模板 | 模板默认内容,末尾加"3-5 天观察期" |

**主题推断**(从用户问题关键词):
- "皮肤病/掉毛/瘙痒" → diet(过敏可能) 或 beh(应激)
- "外伤/出血" → 直接 P0/P1
- "走路瘸" → beh(行为)
- 默认 → 先看图后定

## 5. 边界(强约束,7 条)

1. **不诊断**:不写"这是 X 病/炎症/过敏",只描述视觉
2. **不开药**:不推荐任何药膏/喷剂/口服药
3. **不替代兽医**:即使看到明显异常,也只说"建议就医,医生会判断"
4. **图片质量差**:不强行判断,要求重拍
5. **非宠物图片**:礼貌说明"本 skill 仅识别宠物"
6. **隐私保护**:用户图片不写入永久记忆,处理后立即丢弃
7. **不存储图片**:本 skill 不缓存图片,也不上传第三方

## 6. 输出模板

### 6.1 🔴 P0 输出

```
⚠️ 立即就医

从你发的图片看, [图片描述,1-2 句]。

这是 **急症**,需要 **立即(数小时内)** 兽医处理。本 skill 是照护咨询,不替代兽医诊断。

建议:
1. 立即拨打常去宠物医院急诊电话
2. 如有 24 小时动物急诊,直接前往
3. 路上:保持宠物安静、保暖、避免触碰患处
```

### 6.2 🟡 P1 输出

```
建议 24-48 小时内就医

从图片看到 [图片描述,2-3 句,含部位/外观/程度]。

[加载对应主题模板 6 节输出,但在"风险信号"中加图片描述,在"兽医转介触发器"中加:]

📷 图片相关:
- 图片显示 [简述],建议让医生在诊室查看图片或现场检查
- 不要自行涂抹药膏/喷剂
```

### 6.3 🟢 P2 输出

```
观察 3-5 天

从图片看 [图片描述,1-2 句],**目前不严重**。

[加载对应主题模板 6 节输出,末尾加:]

📷 观察期(3-5 天):
- 每天拍照对比,记录变化
- 如加重(范围扩大/程度加深/出现新症状)→ 升级为 P1
- 如出现全身症状(拒食/精神萎靡)→ 升级为 P0
```

## 7. 与 v1.0 文本问答的衔接

```
用户发图片
  ↓
Step 0.5: 图片质量检查(本文件 § 3.1)
  ↓
通过 → Step 1: 视觉描述(本文件 § 3.2)
  ↓
Step 2: 风险分级(本文件 § 3.3)
  ↓
根据等级:
  P0 → 直接 P0 转介话术(不加载模板)
  P1 → 加载对应主题模板,在"风险信号"和"兽医转介触发器"加图片描述
  P2 → 加载对应主题模板,末尾加"3-5 天观察期"
  ↓
Step 3: 输出 6 节(或 P0 简版)
```

## 8. 已知限制(v1.1 范围)

- **不解读** X 光/CT/MRI 影像
- **不判断** 血液/粪便/尿液检查结果
- **不分析** 心理/行为深度问题(用 beh 模板)
- **不存储** 用户图片(隐私)
- **不能识别** 体内疾病(需兽医器械)
- **依赖 LLM vision 能力**:不同 LLM 识别精度不同,**医生永远更准**
