# 模板:beh-adult(成龄行为与训练)

> **覆盖物种**:猫 / 狗 / 兔 / 鸟 / 鼠(共 5 个完整范例)
> **月龄段**:成(`adult`,物种特异)
> **对应场景 ID 前缀**:`{species}-beh-adult-01`
> **使用方式**:SKILL.md 调度时,根据用户输入的 `species` 加载对应物种章节

## 总体原则(全物种共用)

1. **健康先排查**:任何成年后新出现的行为问题(攻击/乱尿/自残)→ **第一件事是就医**,不是训练
2. **正向强化唯一**:奖励正确行为,忽略错误行为,绝不体罚
3. **环境是根因**:压力/无聊/资源不足 → 行为问题,先改环境再训行为
4. **全家一致**:训练规则必须全家统一
5. **严重问题转介**:持续攻击/自残/严重分离焦虑/严重强迫行为 → 兽医 + 动物行为学家联合评估
6. **本 skill 不替代行为学家**:以下内容为基础训练/调适建议,严重个案需一对一评估

## 1. 猫(cat)| 成龄问题行为(乱尿/攻击/抓挠)

> 场景 ID:`cat-beh-adult-01`
> 月龄定义:1-10 岁
> 模板版本:v0.3.1

### 1.1 场景定位

你问的是 1-10 岁成猫的常见行为问题(乱尿/攻击/破坏性抓挠/夜间嚎叫),核心是**先排除健康问题**(乱尿 = 泌尿道,攻击 = 疼痛,嚎叫 = 甲亢),再针对环境压力和资源布局进行干预,严重个案需转介动物行为学家。

### 1.2 核心建议

1. **乱尿 = 先排除泌尿道**:**任何乱尿第一步是就医**(尿检 + 触诊),尿频/血尿/蹲盆不尿 = **24 小时急症**(公猫尿闭可致肾衰)
2. **砂盆黄金法则**:**n+1 原则**(猫数量 + 1 个),每只猫分开摆放,**绝不** 放在食水旁
3. **资源充足**:每只猫独立食盆/水盆/砂盆/休息区,避免多猫争抢
4. **环境丰容**:垂直空间(猫爬架/壁挂跳台)、磨爪柱、每日 15-30 分钟互动游戏
5. **环境压力排查**:搬家/新宠物/新婴儿/家具大改 → 猫会应激,Feliway 信息素可辅助
6. **禁忌**:任何喷水/打/吼/将猫关笼惩罚,会**加重** 攻击和乱尿

### 1.3 关键参数

| 问题行为 | 干预重点 | 时长/频率 | 关键参数 |
|---|---|---|---|
| 乱尿(已排除泌尿) | 砂盆 + 清洁 + 信息素 | 持续 4-8 周 | 酶清洁剂彻底去味 |
| 同种攻击 | 多猫资源 + 渐进引入 | 持续 2-4 周 | 隔离再逐步接触 |
| 对人攻击 | 不回应 + 空间 + 就医 | 持续观察 | 排除疼痛 |
| 抓挠家具 | 抓挠柱 + 修剪指甲 | 持续 | 柱放休息区旁 |
| 夜间嚎叫 | 不回应 + 运动量 + 就医 | 持续 | 排除甲亢/认知障碍 |

> ⚠️ **乱尿记录**:拍下猫在哪尿/尿量/颜色,就医时给医生,避免反复。

### 1.4 常见误区

1. ❌ **乱尿就认定"报复"**:绝大多数乱尿是**健康或环境原因**,不是报复,惩罚会让问题更严重
2. ❌ **将猫"关起来"惩罚**:致应激和攻击,应**反向** 操作(关砂盆"奖励"区,不是关笼)
3. ❌ **新猫直接合笼**:需 1-2 周隔离 → 气味交换 → 视觉接触 → 物理接触,直接合会持续打架
4. ❌ **不查公猫去势**:未绝育公猫 80% 成年后乱尿圈地,7-8 月龄前绝育可避免
5. ❌ **用醋/氨水除味**:气味类似尿,反而吸引猫再尿,用**酶清洁剂**(Enzymatic Cleaner)

### 1.5 风险信号(立即排查)

- **蹲砂盆不尿或尿极少** = 泌尿道急症,24h 内就医
- **血尿/尿频/排尿疼痛** = 立即就医
- 突然攻击触碰某部位 = **疼痛信号**,先就医
- 公猫反复去砂盆但无尿 = 尿闭,数小时可致肾衰
- 任何突然行为变化(攻击/躲藏/拒食) = 先排查健康
- 持续嚎叫伴消瘦 = 可能甲亢(老年猫)
- 任何自残(过度舔毛/咬尾)

### 1.6 兽医转介触发器

本回答为通用照护建议,不构成兽医/行为学专业建议,以下情况必须立即咨询:
- **任何乱尿先就医排除泌尿问题**(绝对第一优先级)
- **公猫尿闭/排尿困难 = 数小时急症**
- 持续攻击、严重自残(兽医 + 动物行为学家联合评估)
- 健康排除后仍乱尿(动物行为学家评估)
- 突然行为变化(可能疼痛/认知/内分泌)
- 已知慢性病(甲亢/肾病)的相关行为

## 2. 狗(dog)| 成龄问题行为(分离焦虑/吠叫/攻击)

> 场景 ID:`dog-beh-adult-01`
> 月龄定义:小型犬 1-10 岁,大型犬 1.5-7 岁
> 模板版本:v0.3.1

### 2.1 场景定位

你问的是成犬的常见行为问题(分离焦虑/吠叫/牵绳爆冲/攻击/资源保护),核心是**先排除健康原因**(攻击 = 可能疼痛/内分泌/甲亢,突然破坏 = 可能分离焦虑/焦虑症),再通过环境管理 + 行为训练 + 必要时就医,严重个案需兽医 + 动物行为学家。

### 2.2 核心建议

1. **突然攻击 = 先排除疼痛**:触碰某部位时攻击/退避,**第一件事是就医**(骨科/皮肤/耳/甲亢)
2. **分离焦虑渐进脱敏**:从 1 分钟出门起步(不告别),每天加 5-10 分钟,数周达到 4 小时
3. **吠叫不强化**:门口吠/求关注吠 → **不** 回应(不看/不说话/不动),安静时立即奖励
4. **牵绳爆冲**:停步法(爆冲=停下,拉紧=停),**不** 扯回,需一致 2-3 周见效
5. **资源保护**:碗/骨头/窝 → 训练"换"的口令(用更好食物交换),不抢
6. **禁忌**:**任何** 体罚(P 字链/电击项圈/打/吼)→ 已证明**无效且加重攻击**,绝不推荐

### 2.3 关键参数

| 问题行为 | 干预方法 | 时长/频率 | 关键参数 |
|---|---|---|---|
| 分离焦虑 | 渐进脱敏 + 独处训练 | 每天 2-3 次,4-8 周 | 不告别不迎接 |
| 吠叫 | 不回应 + 安静奖励 | 持续 2-4 周 | 全家一致 |
| 牵绳爆冲 | 停步法 + 方向变化 | 每次遛狗 | 5-10 分钟/次 |
| 资源保护 | 换口令 + 高级零食 | 每天 1-2 次 | 不强抢 |
| 对人攻击 | 就医 + 行为学家 | 一对一 | 排查疼痛 |

> ⚠️ **分离焦虑的"不告别"**:出门/回家不打招呼(不摸不说不看),让出门/回家变得不"特别",焦虑信号会随之一致消退。

### 2.4 常见误区

1. ❌ **电击项圈/防吠项圈**:2014 年以来多国研究证明**增加** 攻击和恐惧,**无训练效果**,不推荐
2. ❌ **"打"纠正错误**:会致恐惧攻击,正确做法是**忽略错误 + 奖励正确**
3. ❌ **出门前长时间告别/回家激动迎接**:加重分离焦虑
4. ❌ **把狗"丢去训练营"速成**:行为问题 80% 来自主人互动,训练营结束回家老样子
5. ❌ **突然攻击就"安乐"思考**:绝大多数攻击可矫正,先就医 + 行为学家

### 2.5 风险信号(立即排查)

- 突然攻击、碰某部位就咬 → **先排除疼痛**
- 持续自残(舔/咬自己至出血)
- 主人离开后**严重破坏门/窗** + 自残
- 7 岁以上突然出现"乱尿/嗜睡/攻击"(甲亢/认知/疼痛信号)
- 任何咬人致破皮事件
- 服用任何药物后行为突变(可能药物副作用)
- 突然持续发抖、躲藏(可能中毒/癫痫)

### 2.6 兽医转介触发器

本回答为通用照护建议,不构成兽医/行为学专业建议,以下情况必须咨询:
- **任何突然行为变化先就医**(疼痛/甲亢/糖尿病/认知)
- 持续攻击、严重自残(兽医 + 动物行为学家联合评估,**必须** 用药评估)
- 严重分离焦虑(自残/严重破坏)
- 资源保护升级为咬人
- 7 岁以上突然行为变化(老年病筛查)
- 已知慢性病用药下的行为变化

## 3. 兔(rabbit)| 成龄问题行为(咬人/乱尿/破坏)

> 场景 ID:`rabbit-beh-adult-01`
> 月龄定义:6 月-5 岁
> 模板版本:v0.3.1

### 3.1 场景定位

你问的是成兔的常见行为问题(咬人/乱尿/圈地/破坏性咬物),核心是**先排除健康原因**(攻击 = 疼痛/未绝育/领地,乱尿 = 泌尿道/未绝育/圈地),再通过绝育 + 环境丰容 + 行为调适干预,严重问题转介兔科专科。

### 3.2 核心建议

1. **攻击/圈地/乱尿 = 80% 未绝育**:**4-6 月龄绝育后,80% 行为问题 4-8 周内改善**,母兔未绝育 4 岁后子宫病变高发
2. **乱尿先排除健康**:尿频/血尿/排尿痛 = 立即就医,排除泌尿道感染/结石
3. **环境丰容防破坏**:提供磨牙木、挖掘盒、隧道,缺乏导致咬家具/电线(致死)
4. **抱法矫正**:不抓耳朵/后颈皮,改"一手托胸、一手托后腿",**90% 咬人来自错误抱姿导致的恐惧**
5. **不要追逐**:兔是猎物,追逐触发逃跑和惊恐反应
6. **禁忌**:任何打、喷水、关笼惩罚,兔不会因此改变行为,只会更怕人

### 3.3 关键参数

| 问题行为 | 干预重点 | 时长/频率 | 关键参数 |
|---|---|---|---|
| 圈地/攻击(未绝育) | 绝育手术 | 4-8 周恢复 | 4-6 月龄最佳 |
| 乱尿(已排除健康) | 多个低边盆 + 绝育 | 持续 2-4 周 | 角落放置 |
| 破坏性咬物 | 磨牙木 + 放风 | 每天 ≥ 3-4 小时 | 电线需防咬 |
| 怕人躲藏 | 蹲下 + 不追 | 持续 2-4 周 | 每天 5-10 分钟 |

### 3.4 常见误区

1. ❌ **不认为兔需要绝育**:兔的绝育是行为和健康双重必须,不是"残忍"
2. ❌ **追赶/强行抓出**:兔会激烈反抗,可能脊椎骨折(致死),也会让人对兔产生恐惧
3. ❌ **长期笼养**:兔需每天 3-4 小时以上放风+大空间,否则刻板行为
4. ❌ **喷水/打惩罚**:兔不会"记住错误",只记住"人=危险"
5. ❌ **不提供磨牙料**:兔牙终身生长,缺磨牙致咬合不正(见 `diet-adult`)

### 3.5 风险信号(立即排查)

- 突然攻击、甩头 → **先排除疼痛**(牙齿/消化/骨科)
- 突然乱尿(尤其 1 岁后) → **先排除泌尿**(感染/结石)
- 不排便/粪便变小(GI 停滞急症)
- 持续侧躺/拱背(可能疼痛)
- 牙齿过长/流涎
- 后肢突然瘫痪(可能脊椎损伤)

### 3.6 兽医转介触发器

本回答为通用照护建议,不构成兽医/行为学专业建议,以下情况必须咨询:
- **任何突然行为变化先排除健康问题**(牙齿/消化/骨科/寄生虫)
- 任何疑似 GI 停滞(数小时急症)
- 任何急性瘫痪/共济失调
- 6 月龄后未绝育(强烈推荐)
- 已知牙齿咬合不正/慢性疼痛
- 持续攻击兔(可能未绝育+慢性问题)

## 4. 鸟(bird)| 成龄问题行为(尖叫/拔羽/咬人)

> 场景 ID:`bird-beh-adult-01`
> 月龄定义:中小型 1-8 年,大型 2-15 年
> 模板版本:v0.3.1

### 4.1 场景定位

你问的是成鸟的常见行为问题(尖叫/拔羽/咬人/发情攻击),核心是**先排除健康原因**(拔羽 = PBFD/营养/寄生虫,行为突变 = 疼痛/感染),再通过环境管理(睡眠+丰容)+ 行为调适(不强化尖叫)+ 必要时就医,严重个案转介鸟类专科 + 鸟类行为学家。

### 4.2 核心建议

1. **拔羽 = 第一件事是就医**:**任何持续拔羽先查 PBFD/螨虫/营养/内分泌**,排除健康后才考虑行为
2. **睡眠是核心**:**10-12 小时黑暗不被打扰睡眠** 是预防尖叫/拔羽/攻击最关键的一环
3. **不强化尖叫**:日落前后和早晨的"自然呼叫"是正常的,但**持续尖叫/尖叫求关注 → 不回应**,安静立即互动
4. **咬人"无反应"**:被咬**不** 尖叫/不抽手(鸟会学"咬就有反应"),改静止或放回笼
5. **丰容必做**:啃咬玩具、觅食玩具、洗澡盘、爬梯,**鸟智商等同 4-7 岁儿童**,无聊 = 行为问题
6. **发情期行为**:5-7 月发情,公鸟易攻击、拔羽、产蛋,**可咨询绝育**(风险大,需专业鸟医)

### 4.3 关键参数

| 问题行为 | 干预方法 | 时长/频率 | 关键参数 |
|---|---|---|---|
| 持续尖叫 | 不回应 + 睡眠 + 丰容 | 持续 2-4 周 | 全家一致 |
| 拔羽(已排除健康) | 丰容 + 喷雾 + 减压 | 持续观察 | 反复就医排查 |
| 咬人 | 无反应 + 放回笼 | 每次 | 不惩罚 |
| 发情攻击 | 减光 + 减蛋白 + 就医 | 持续 | 咨询鸟类专科 |
| 啄羽/自残 | 就医 + 行为学家 | 一对一 | 排查 PBFD |

> ⚠️ **啄羽(Feather Plucking)是鸟类的"红旗信号"**:持续 24h 以上必须就医,可能是 PBFD(致死性病毒)/螨虫/肝脏/心理问题。

### 4.4 常见误区

1. ❌ **尖叫就回喊/出笼回应**:让鸟学会"叫就有回报",问题升级
2. ❌ **打鸟嘴/关黑笼惩罚**:致严重恐惧和攻击,**无训练效果**
3. ❌ **不重视睡眠**:很多"行为问题"是睡眠不足所致
4. ❌ **没有啃咬玩具**:鹦鹉喙终身生长,需啃咬,否则啄羽/啄人
5. ❌ **认为"拔羽只是审美"**:拔羽是医疗 + 心理双重警报,**不是小事**

### 4.5 风险信号(立即排查)

- **持续拔羽至出血** → 立即就医(感染+自残)
- 突然嗜睡/食欲下降 = 急症
- 粪便异常(稀/绿/有血)
- 呼吸异常(张嘴喘/呼吸有声音)
- 突然攻击性大增(可能疼痛或内分泌)
- 7 岁以上突然行为变化(肝/肾/肿瘤)
- 任何羽毛蓬乱 + 闭眼(可能感染)

### 4.6 兽医转介触发器

本回答为通用照护建议,不构成兽医/行为学专业建议,以下情况必须咨询鸟类专科兽医:
- **任何持续拔羽**(先排除 PBFD/螨虫/营养/内分泌)
- **自残行为**(兽医 + 鸟类行为学家)
- 持续嗜睡/食欲下降
- 任何呼吸道症状
- 已知 PBFD/慢性肝病
- 任何急性中毒/感染迹象

## 5. 鼠(rodent,含仓鼠/豚鼠/花枝鼠)| 成龄问题行为(咬人/刻板)

> 场景 ID:`rodent-beh-adult-01`
> 月龄定义:仓鼠 3-18 月,豚鼠 6 月-4 岁,花枝鼠 4-18 月
> 模板版本:v0.3.1

### 5.1 场景定位

你问的是成鼠的常见行为问题(咬人/刻板转圈/啃笼/打架),核心是**先排除健康原因**(咬人 = 疼痛/被吓/打斗,刻板 = 笼子过小/无聊/孤独),再通过饲养方式修正(**仓鼠必须独居**)+ 环境丰容 + 渐进脱敏,严重问题转介啮齿类专科。

### 5.2 核心建议

1. **仓鼠独居铁律**:**任何品种仓鼠(叙利亚/加卡利亚/罗伯罗夫斯基/中国)都必须独居**,合笼**必死**,**先** 排查"笼中另一只仓鼠是否被欺负"
2. **刻板行为 = 笼子过小/缺丰容**:转圈、啃笼、爬同路径 = 心理问题,需**至少 80×50cm 笼 + 跑轮 + 挖掘垫料**
3. **咬人先排除疼痛**:触碰某部位时咬 = **就医**(牙齿/肿瘤/皮肤)
4. **不叫醒/不强行抓**:仓鼠夜行,白天强行互动致应激咬人
5. **不水洗**:鼠类会自洁,水洗致体温过低和应激
6. **豚鼠/花枝鼠群居需求**:独养易抑郁和行为问题,需**同性 2+ 群居**

### 5.3 关键参数

| 问题行为 | 干预方法 | 时长/频率 | 关键参数 |
|---|---|---|---|
| 咬人(无疼痛) | 渐进脱敏 + 食物引诱 | 每天 5-10 分钟 | 不从头顶 |
| 刻板转圈 | 笼升级 + 跑轮 + 丰容 | 持续 | 仓鼠笼 ≥ 80×50cm |
| 啃笼 | 大笼 + 啃咬玩具 | 持续 | 笼子过小的标志 |
| 仓鼠打架 | **立即分笼** | - | 不可逆,合笼必致伤亡 |
| 豚鼠/花枝鼠孤僻 | 加同伴(同性) | - | 需逐步引入 |

> ⚠️ **仓鼠合笼致死率几乎 100%**:即使幼年同窝、即使"看起来没事",成年后**必** 分笼。这是 90% 仓鼠死亡原因之一。

### 5.4 常见误区

1. ❌ **仓鼠合笼**:无论品种/性别/年龄,**严格独居**,这不容讨论
2. ❌ **笼子过小**(仓鼠 < 80×50cm):直接致刻板行为
3. ❌ **水洗鼠**:用沙浴(仓鼠)/湿巾擦(豚鼠)
4. ❌ **从头顶抓**:猎物本能,致终生恐惧
5. ❌ **白天强行互动**:仓鼠白天睡觉,被叫醒会应激咬人

### 5.5 风险信号(立即排查)

- 突然蜷缩、毛发蓬乱、不食 = **可能生病**
- **湿尾症**(仓鼠腹泻+肛门湿) = 数天急症
- 持续咬人致出血
- 持续刻板行为(转圈/啃笼)
- 牙齿过长/流涎
- 合笼鼠打架致伤 = **立即分笼**
- 任何皮下肿块(肿瘤,老年鼠高发)

### 5.6 兽医转介触发器

本回答为通用照护建议,不构成兽医/行为学专业建议,以下情况必须咨询啮齿类专科兽医:
- **任何突然行为变化先排除健康问题**(湿尾症、肿瘤、牙齿)
- 持续自残、严重刻板行为
- 任何疑似湿尾症
- 牙齿明显过长/口腔出血
- 任何皮下肿块
- 任何外伤/出血
