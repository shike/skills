1. 异宠医疗资源稀缺,**任何异常都建议咨询异宠专科兽医**(爬宠专科,非普通宠物医院)

## 通用方法论(全龄蛇)

1. **环境三要素**:温度梯度(热区 28-32℃ / 冷区 22-25℃)+ 湿度(40-60%,蜕皮期 60-80%)+ 躲避(必备 2 个,分置热冷区)
2. **食物大小**:猎物宽度 ≤ 蛇身最粗处 1-1.5 倍,解冻至室温 30-35℃ 后投喂
3. **蜕皮管理**:提供湿润躲避/水盆,蜕皮不全需温水浸泡+人工辅助,**绝不可强行撕皮**
4. **绝对单养**:蛇无社交需求,合养致互相伤害/吞食/严重应激
5. **观察为先**:记录每次进食/蜕皮/排泄,异常立即就医

### 1. 场景定位

你问的是常见宠物蛇(玉米蛇/球蟒/王蛇,全龄不分段)的照护问题。核心是**温度梯度 + 湿度 + 躲避 + 食物大小 + 绝对单养**。蛇寿命 15-30 年,异常隐匿(数月不食外观正常),**任何异常都建议爬宠专科**。

### 2. 核心建议

1. **环境三要素**:温度梯度(热区 28-32℃ + 冷区 22-25℃,加热垫需配温控)+ 湿度 40-60%(蜕皮期升至 60-80%)+ 至少 2 个躲避(热冷区各 1)
2. **食物大小与频率**:解冻乳鼠/成年鼠(宽度 ≤ 蛇身最粗处 1-1.5 倍),幼蛇 5-7 天/次,成蛇 7-14 天/次
3. **蜕皮管理**:提供湿润躲避/水盆,蜕皮前眼睛变蓝(蒙眼期)勿打扰,蜕皮期拒食属正常
4. **绝对单养**:无论同种/异种/公母/大小,**绝不合养**(互咬/吞食/严重应激致死)
5. **异常立即就医**:拒食 > 2-3 个周期/口腔黏液/蜕皮不全/张口呼吸/皮肤水疱 → **当天爬宠专科**

### 3. 关键参数

| 项目 | 参数 | 备注 |
|---|---|---|
| 热区温度 | 28-32℃ | 加热垫/陶瓷灯 + 温控,需温度计实测 |
| 冷区温度 | 22-25℃ | 与室温持平,提供选择 |
| 夜间温度 | 可降至 22℃ | 模拟自然昼夜 |
| 日常湿度 | 40-60% | 湿度计监测 |
| 蜕皮期湿度 | 60-80% | 湿润躲避/水盆/覆盖湿苔藓 |
| 躲避数量 | ≥ 2 个 | 热冷区各 1,大小以蛇贴壁为宜 |
| 食物大小 | 宽度 ≤ 蛇身最粗 1-1.5 倍 | 解冻至 30-35℃ 投喂 |
| 喂食频率(幼) | 5-7 天/次 | 5-7 日龄乳鼠 |
| 喂食频率(成) | 7-14 天/次 | 视体型调整 |
| 喂食后处理 | 48h 内不打扰 | 防吐食 |

> ⚠️ **加热垫需配温控**:加热垫直接接触蛇腹可致严重烫伤(蛇神经反应慢,烫伤后才发现)。

### 4. 常见误区

1. ❌ **两条蛇合养**:蛇独居动物,合养致互相攻击/吞食/严重应激致死,**绝对单养**
2. ❌ **喂活饵**:活鼠会反咬致蛇严重外伤/感染,**必须喂预先处死并完全解冻的饵料**
3. ❌ **加热垫不配温控**:过热致腹鳞烫伤(慢性,数周后才显现),**必须配温控 + 温度计**
4. ❌ **强行撕蜕皮中/蒙眼期的蛇**:致皮肤损伤/感染,蜕皮不全需温水浸泡后轻柔辅助
5. ❌ **长期拒食不就医**:蛇代谢慢,数月不食仍活动,**但已是严重信号**,需异宠专科排查
6. ❌ **用家用白炽灯/太阳灯作为唯一热源**:无 UVB 不影响蛇,但需注意灯泡表面温度致烫伤

### 5. 风险信号(立即就医)

- 🔴 持续拒食 > 2-3 个正常喂食周期
- 🔴 口腔黏液/泡沫/张嘴呼吸/呼吸有杂音(呼吸道感染,急症)
- 🔴 口腔红肿/齿龈可见奶酪样物(口腔炎,传染性,需隔离环境)
- 🔴 蜕皮不全(尤其眼罩/尾尖残留,致感染/坏死)
- 🔴 皮肤水疱/红斑/异常鳞片下液体(烫伤/水疱性皮病,可能致命)
- 🔴 长时间张嘴/流涎/无法闭口
- 🟡 排泄异常(稀/带血/不排 > 1 个月)
- 🟡 持续蜷缩在冷区不动 > 数日

### 6. 兽医转介触发器(爬宠专科)

本回答为通用照护建议,**爬宠专科资源稀缺(全国仅少数医院),任何异常请直接就医**:

- 🔴 任何持续拒食 > 2-3 个周期
- 🔴 任何呼吸道症状(张嘴呼吸/黏液/杂音)
- 🔴 任何口腔红肿/奶酪样物(口腔炎)
- 🔴 任何蜕皮不全(尤其眼罩残留)
- 🔴 任何皮肤水疱/烫伤迹象
- 🔴 任何外伤/出血/被咬伤(包括被活饵反咬)
- 🔴 长期未排/排便带血
- 🟡 体重持续下降/体形明显消瘦
