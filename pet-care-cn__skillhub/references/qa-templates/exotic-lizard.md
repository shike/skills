# 模板:exotic-lizard(常见宠物蜥蜴,全龄通用)

> **覆盖物种**:常见宠物蜥蜴(鬃狮蜥 Bearded Dragon / 豹纹守宫 Leopard Gecko / 绿鬣蜥 Green Iguana)
> **月龄段**:全龄(不分幼/成/老,物种间差异远大于年龄差异)
> **对应场景 ID**:`{species}-exotic-{age}-01`
> **使用方式**:SKILL.md 调度时,根据用户输入的 `species` 加载本模板

## 异宠强转诊原则(本模板通用)

⚠️ **异宠照护核心原则**:
1. 异宠医疗资源稀缺,**任何异常都建议咨询异宠专科兽医**
2. 本 skill 给基础照护框架,**不做诊断,不开药**
3. 异宠病情隐匿,发现症状时往往已较重,**不要等,不要观察,直接就医**

## 通用方法论(全龄蜥蜴)

1. **环境为王**:UVB 灯(必须)+ 温度梯度(晒点 + 冷区)+ 物种特异湿度
2. **饮食分类**:鬃狮蜥/绿鬣蜥偏植食,豹纹守宫肉食——**物种错误致营养不良**
3. **钙 + 维 D3**:UVB 灯促进 D3 合成,食物补钙,二者缺一不可
4. **温控器必装**:夜间温度不低于 20℃,否则拒食/免疫力下降
5. **观察为先**:每日观察活动/食欲/排泄,异常立即就医

## 6 节输出结构(本模板范例)

### 1. 场景定位

你问的是常见宠物蜥蜴(鬃狮蜥/豹纹守宫/绿鬣蜥)全龄照护。核心是 **UVB 灯 + 温度梯度 + 钙维 D3 + 物种特异饮食**。寿命 5-20 年(守宫 5-10 年,鬃狮 8-12 年,绿鬣蜥 15-20 年),MBD/呼吸道感染/寄生虫为常见急症,**任何异常都建议异宠专科**。

### 2. 核心建议

1. **环境三件套**:UVB 灯(必须,每日 10-12h)+ 温度梯度(晒点 38-42℃ / 冷区 24-28℃)+ 物种特异湿度
2. **补钙 + 维 D3**:每餐撒无 D3 钙粉,**每周 1-2 次含 D3 钙粉**(幼体可每餐含 D3),UVB 灯促进 D3 体内合成
3. **饮食分类**:鬃狮蜥幼体 50% 蛋白 + 50% 菜,成体 80% 菜 + 20% 蛋白;绿鬣蜥成体 80% 深绿叶菜;**豹纹守宫全肉食(昆虫为主)**
4. **夜间保温**:全缸温控,**不低于 20℃**(豹纹守宫可至 22℃),温控器 + 备用加热
5. **异常即转诊**:腿软/壳软/颌骨变形/张嘴呼吸/拒食 → **当天异宠专科**

### 3. 关键参数

| 项目 | 参数 | 备注 |
|---|---|---|
| 晒点温度 | 38-42℃(鬃狮/绿鬣蜥) | 灯下温度计测 |
| 冷区温度 | 24-28℃ | 昼夜均需监测 |
| 夜间温度 | ≥ 20℃ | 豹纹守宫可至 22℃ |
| UVB 灯 | 10.0(沙漠种)或 5.0(雨林种) | **每 6-12 月换新** |
| UVB 时长 | 10-12h/日 | 定时器控制 |
| 湿度 | 鬃狮 30-40%,绿鬣蜥 60-80%,豹纹守宫 30-40% | 物种差异显著 |
| 补钙(无 D3) | 每餐 | 撒食物上 |
| 补钙(含 D3) | 每周 1-2 次 | 幼体可每餐 |
| 绿鬣蜥泡澡 | 2-3 次/周,30 分钟 | 防脱水/助排酸 |

> ⚠️ **UVB 灯每 6-12 月换新**:UVB 强度会衰减,即使灯还亮,UVB 已失效,致 MBD。

### 4. 常见误区

1. ❌ **不装 UVB 灯 / 用加热灯代替**:致 MBD(代谢性骨病),表现为腿软/抽搐/颌骨变形/壳软,不可逆
2. ❌ **玻璃缸晒太阳**:玻璃阻挡 UVB,**必须户外直射**(注意防逃/防中暑)
3. ❌ **单一素食喂豹纹守宫**:守宫是肉食种,只吃昆虫,素食致营养不良/拒食
4. ❌ **单一肉食喂绿鬣蜥**:绿鬣蜥成体需 80% 植物,蛋白过多致肾负担/痛风
5. ❌ **不装温控器**:夜间温度可跌至 15℃ 以下,致拒食/免疫力崩溃
6. ❌ **喂野生昆虫**:寄生虫风险高,需用饲养昆虫(蟋蟀/杜比亚)

### 5. 风险信号(立即就医)

- 🔴 腿软/抽搐/颌骨变形/壳软(MBD 急症,不可逆)
- 🔴 张嘴呼吸/流鼻涕/嘴角有黏液(呼吸道感染,急症)
- 🔴 拒食 > 3-7 天(成体)/ > 1 天(幼体)
- 🔴 嗜睡 + 无反应
- 🔴 体重持续下降
- 🟡 排泄异常(稀/带血/不排)
- 🟡 皮肤异常(脱皮不全/肿块/变色)
- 🟡 粪便见虫体/异常消瘦(疑似寄生虫)

### 6. 兽医转介触发器(异宠专科)

本回答为通用照护建议,**异宠专科资源稀缺,任何异常请直接就医**:

- 🔴 任何腿软/颌骨变形/壳软(MBD 急症)
- 🔴 任何呼吸道症状(张嘴呼吸/流鼻涕)
- 🔴 任何疑似寄生虫(粪便见虫/异常消瘦/拒食伴腹泻)
- 🔴 任何拒食 > 3-7 天(成体)/ > 1 天(幼体)
- 🔴 任何嗜睡 + 无反应
- 🔴 任何体重持续下降
- 🟡 排泄异常 > 1 周
- 🟡 皮肤异常(脱皮不全/肿块)
- **强转诊异宠专科**:本 skill 不开药,所有药物(钙/维 D3/抗生素/驱虫药)剂量由异宠专科开具
- **普通宠物医院可能不接异宠**:就医前电话确认异宠专科,避免白跑
