# 模板:exotic-parrot-large(大型鹦鹉,全龄通用)

> **覆盖物种**:大型鹦鹉(金刚鹦鹉 Macaw / 亚马逊鹦鹉 Amazon / 非洲灰鹦鹉 African Grey,泛指)
> **月龄段**:全龄(不分幼/成/老,寿命 30-80 年,分段意义小)
> **对应场景 ID**:`{species}-exotic-{age}-01`
> **使用方式**:SKILL.md 调度时,根据用户输入的 `species` 加载本模板

## 异宠强转诊原则(本模板通用)

⚠️ **异宠照护核心原则**:
1. 异宠医疗资源稀缺,**任何异常都建议咨询异宠专科兽医**(禽类专科)
2. 本 skill 给基础照护框架,**不做诊断,不开药**
3. 大型鹦鹉**呼吸道极度敏感**,室内空气清新剂/烟雾/油烟可致命,**环境问题=生死问题**
4. 大型鹦鹉**高陪伴需求**,长期独处致严重心理问题(啄羽/抑郁/自残),**心理问题=生死问题**

## 通用方法论(全龄大型鹦鹉)

1. **环境优先**:温度 18-26℃ + 湿度 50-70% + 通风,**禁烟/禁清新剂/禁 Teflon 高温烟雾**
2. **高陪伴高互动**:每日 ≥2-4 小时人鸟互动,否则啄羽/抑郁
3. **复杂饮食**:滋养丸(主) + 蔬菜(辅) + 少量种子/坚果(奖励),**绝不能单一种子粮**
4. **终身心理健康**:丰容玩具/啃咬物/训练,智商等同 4-7 岁儿童,长期无聊=行为病
5. **观察为先**:每日观察羽毛/粪便/食欲/行为,异常当天就医

## 6 节输出结构(本模板范例)

### 1. 场景定位

你问的是大型鹦鹉(金刚/亚马逊/灰机,全龄不分段)的照护问题。核心是**复杂饮食(滋养丸+蔬菜)+ 高陪伴 + 严格空气管理(无烟无清新剂) + 心理健康(防啄羽)**。寿命 30-80 年,**长期独处致啄羽/抑郁,空气污染致呼吸道死亡,任何异常都建议异宠(禽类)专科**。

### 2. 核心建议

1. **环境空气红线**:禁烟/禁空气清新剂/禁香薰/禁 Teflon 高温烟雾(PTFE 中毒 30 分钟内死亡),**通风>一切**
2. **饮食结构**:滋养丸 60-70% + 蔬菜 20-30% + 种子/坚果 <10%(奖励用),**禁纯种子粮/禁巧克力/牛油果/酒精**
3. **陪伴与丰容**:每日 ≥2-4 小时互动 + 啃咬/觅食玩具/训练,**长期独处致啄羽/抑郁/自残**
4. **笼舍与活动**:笼 ≥ 1.5×1×1.5 m(可展翅)+ 每日放出活动 2-4 小时
5. **异常立即就医**:啄羽/消瘦/呼吸异常/羽毛异常/粪便异色 → **当天禽类专科**

### 3. 关键参数

| 项目 | 参数 | 备注 |
|---|---|---|
| 室温 | 18-26℃ | 避免骤变,直吹致呼吸道感染 |
| 湿度 | 50-70% | 干燥致羽毛/呼吸道问题 |
| 光照 | 12h 明(含 UV)/12h 暗 | 全光谱灯助 D3 合成 |
| 滋养丸占比 | 60-70% | 主粮,定时定量防挑食 |
| 蔬菜占比 | 20-30% | 深绿叶/彩椒,**禁牛油果/洋葱** |
| 种子/坚果 | <10% | 高脂,仅奖励/训练用 |
| 互动时长 | ≥ 2-4 h/日 | 心理与行为健康基础 |
| 笼舍尺寸 | ≥ 1.5×1×1.5 m | 可展翅,水平+垂直空间 |
| 放出活动 | 2-4 h/日 | 防肥胖/防行为问题 |
| 寿命 | 30-80 年 | 长期承诺,遗弃=心理死刑 |

> ⚠️ **空气安全红线**:烟草/空气清新剂/香薰/Teflon 高温烟雾/油烟/烧香,均可致鹦鹉急性肺炎或死亡,通风>一切,厨房需隔离。

### 4. 常见误区

1. ❌ **单一种子粮为主**:营养严重不全(高脂低维 A/D3/钙),致脂肪肝/啄羽/免疫差,**必须以滋养丸为主**
2. ❌ **长期独处**:鹦鹉群居动物,智商等同 4-7 岁儿童,孤独=啄羽/抑郁/尖叫/自残,日均陪伴 <2 小时属虐待
3. ❌ **室内用空气清新剂/香薰/烧香**:化学颗粒致呼吸道炎症/致死,**通风>一切**
4. ❌ **厨房煎炒靠近鸟**:油烟/Teflon 涂层过热释放 PTFE 气体 30 分钟内致死,鸟笼远离厨房
5. ❌ **用小笼/圆笼/不限制坚果**:空间不足致骨骼/心理问题,高脂坚果致脂肪肝,需大方笼+奖励定量

### 5. 风险信号(立即就医)

- 🔴 啄羽/自残/持续拔毛(心理或 PDD/PBFD 信号,需排查)
- 🔴 呼吸急促/张口呼吸/尾羽摆动(呼吸道急症,可能吸入毒素)
- 🔴 粪便异色(绿/黑/带血)或水样稀便
- 🔴 羽毛异常脱落/羽髓出血(疑似 PBFD,病毒性,强传染)
- 🔴 消瘦/嗉囊停滞(疑似 PDD/感染/肿瘤)
- 🔴 突然嗜睡/炸毛(重症前兆,当日就医)
- 🟡 食欲/行为/叫声突变持续 >1 周(心理或疼痛信号)

### 6. 兽医转介触发器(异宠禽类专科)

本回答为通用照护建议,**异宠(禽类)医疗资源稀缺,任何异常请直接就医**:

- 🔴 任何啄羽/自残行为持续 >1 周(需排查 PBFD/PDD/心理)
- 🔴 任何呼吸异常(张口/喘息/尾摆)→ 急症,可能为毒素吸入
- 🔴 任何粪便异色(绿/黑/血/水样)>24 小时
- 🔴 任何羽毛异常脱落/羽髓出血(疑似 PBFD,需 PCR 确诊,强传染)
- 🔴 任何嗉囊停滞/呕吐/消瘦(疑似 PDD/感染,需钡餐造影)
- 🔴 任何中毒迹象(空气清新剂/Teflon/植物/巧克力/牛油果)
- 🔴 任何外伤/出血/骨折或体重持续下降
- **本 skill 不开药,所有治疗药物(抗生素/止痛/麻醉)剂量由禽类专科开具**
- **鸟类对多数药物敏感(阿莫西林/伊维菌素需谨慎),绝不可自行用药**
- **普通宠物医院多不接禽类,务必找异宠/禽类专科(中国农业大学动物医院禽类门诊或当地异宠协会转介)**
- **PBFD/PDD 需 PCR/抗原检测确诊,治疗方案须专科制定,不可套用犬猫剂量**

**空气质量自查清单**(送医/咨询时同步检查):
- 鸟笼周围是否有人吸烟/烧香/用空气清新剂
- 厨房与鸟笼是否同空间(油烟/Teflon 风险)
- 室内装修/新家具是否近期释放甲醛
- 空气净化器是否带臭氧(臭氧对鸟致命)
